# シミュレーション設計ガイド

記事から参照する検証用コードは「動けばよい」ではなく、**記事が伝えたい主張を実際に示す**ことが求められます。このスキルは、その整合性を保証するプロセスをガイドします。

---

## 原則1: 作業前に記事の核心的な主張を把握する

コードに手を入れる前に、記事が最終的に何を主張しているかを1〜2文に整理してください。`# はじめに` と比較表・選択指針のような結論部分を読むのが最速です。

その主張が「手法Aは手法Bより優れている」という比較であれば、シミュレーション結果の数値がその順序になっているかを事前に確認基準として持っておきます。

> **失敗パターン**: タスクメモの「残タスク」をそのまま実行し、実行後に初めて記事の主張と矛盾することに気づく。コードが動くことを優先して、矛盾した出力例を記事にそのまま載せてしまう。

---

## 原則2: 結果が主張と食い違ったらパラメータを再設計する

シミュレーション結果が記事の主張と矛盾した場合、**結論文や出力例を結果に合わせて書き換えるのは誤り**です。まず「なぜ主張が成立しないのか」の原因を診断し、主張が成立する条件にパラメータを設計し直します。

原因は大きく2種類に分けられます。

1. **モデルがパラメータを正しく推定できていない** — データの信号が雑音に対して弱すぎるため、推定アルゴリズムが意図した挙動をしない
2. **推定手法が分析目的と合っていない** — アルゴリズムの設定（オプション・出力の種類など）が分析のシナリオに合っておらず、本来の性能が出ていない

それぞれの診断と対処は以下の補足を参照してください。

### 補足A: モデルの検出可能性を診断する

モデルがパラメータを「検出できていない」サインとして、推定されたパラメータが境界値（例: 分散 ≈ 0）に収束し統計的に有意でないことが挙げられます。この場合、モデルは実質的に「パラメータが変化しない」仮定に退化しており、RMSE 等の指標が悪化する根本原因になります。

原因は「信号対雑音比（S/N 比）が低すぎる」ことです。S/N 比は、観測データに含まれる「推定したいパラメータの変動に起因するシグナル」と「観測ノイズ」の比として計算できます。比が十分でない場合は、シグナルを強める（変動量を増やす）かノイズを減らすかを検討します。

*具体例（対数価格モデルでの時変弾力性 SSM）:*

```
観測方程式: y_t = alpha_t + beta_t * x_t + ε_t

検出条件: SIGMA_STATE × E[|x_t|]  >>  obs_noise / sqrt(T)

x_t = log(price / PRICE_BASE), 価格レンジ 200-400 円, 基準 300 円 の場合:
  E[|x_t|] ≈ 0.17

SIGMA_STATE=0.05, obs_noise=0.25 のとき:
  信号 = 0.05 × 0.17 = 0.009, 閾値 = 0.25 / sqrt(156) ≈ 0.020
  → 信号 < 閾値 → sigma2_beta ≈ 0 に退化（SSM が定数モデルになる）

obs_noise=0.02 に縮小すると:
  閾値 = 0.02 / sqrt(156) ≈ 0.0016
  → 信号 > 閾値 → sigma2_beta が有意に推定される
```

### 補足B: 推定手法が分析目的と合っているかを確認する

同じアルゴリズムでも、出力として取り出す値の種類によって性能が大きく異なる場合があります。「どの出力を使うか」が分析目的と一致しているかを確認してください。

*具体例（カルマンフィルタ vs カルマンスムーザー）:*

カルマンアルゴリズムには2種類の出力があります。

| | カルマン**フィルタ** | カルマン**スムーザー** |
|---|---|---|
| 使用データ | 時点 t までの過去データのみ（片側） | 全期間のデータ（双方向） |
| 適した用途 | リアルタイム監視・逐次予測 | 過去データの回顧的分析 |
| statsmodels | `result.filtered_state` | `result.smoothed_state` |

「過去データから弾力性の変化を分析する」という回顧的シナリオで `filtered_state`（片側推定）を使うと、本来の性能が出ずにローリングGLMに負けることがあります。この場合は `smoothed_state` に切り替えるだけで精度が大幅に改善します。

## 原則3: 簡略化した条件でよいので主張が成立する設定を見つける

現実のデータを完全に再現する必要はありません。記事の理論的優位性が明確に現れる、教科書的な簡略条件を探してください（高校物理の「摩擦はゼロとする」と同じ発想です）。

簡略化した条件を使う場合は、記事本文に「この例では現実社会の現象からいくつか簡易な仮定を置きシンプルなモデルとしています」と一言添えることで、読者への誠実さを保てます。
