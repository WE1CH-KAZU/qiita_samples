# Markdownフォーマットルール

記事（`.md` ファイル）を執筆・編集する際は以下のルールに従うこと。
GitHub Flavored Markdown（GFM）・CommonMark・Google/Microsoftスタイルガイド・markdownlint のデファクトスタンダードを基準とする。

---

## 見出し

- **ATX形式（`#`）のみ**使う。Setext形式（`===`/`---`）は使わない
- `#` の直後にスペースを1つ入れる（`# タイトル`）
- 見出しの前後に空行を1行入れる
- 見出しレベルはスキップしない（H1 → H3 のようにH2を飛ばさない）
- H1（`#`）はファイル内に1つだけ使い、記事タイトルに充てる
- 見出し末尾に句点・感嘆符などの句読点を付けない
- 見出し内で太字・イタリックなどの装飾は使わない

## リスト

### 箇条書き（順不同リスト）

- マーカーは **ハイフン（`-`）** に統一する（`*` や `+` は使わない）
- マーカーの後にスペースを1つ入れる
- ネストは半角スペース2つのインデントを使う
- 同一リスト内でマーカーの種類を混在させない

### 番号付きリスト

- すべての項目を `1.` で書く（番号をインクリメントしない）。レンダラーが自動採番するため、順序の変更が容易になる
- `.` の後にスペースを1つ入れる

### 共通

- リストの前後に空行を1行入れる
- 1文で完結する項目には句点を付けない
- 複数文にまたがる項目には句点を付ける

## コードブロック

- **フェンス形式（バックティック3つ）** を使う。4スペースインデント形式は使わない
- 開始フェンスには必ず言語識別子を付ける（不明なときは `text`）
- コードブロックの前後に空行を1行入れる

```markdown
```python
# 言語識別子の例
```

```bash
# シェルコマンドの例
```

```text
# 出力例・プレーンテキストの例
```
```

よく使う言語識別子：

| 種別 | 識別子 |
|------|--------|
| Python | `python` |
| シェルコマンド | `bash` |
| 実行結果・出力例 | `text` または `console` |
| YAML | `yaml` |
| JSON | `json` |
| SQL | `sql` |
| Markdown | `markdown` |

## インラインコード

- ファイル名・コマンド名・変数名・短いコードは **バックティック1つ** で囲む（`` `code` ``）
- バックティックの内側にスペースを入れない（`` ` code ` `` は誤り）

## 強調

| 用途 | 記法 | 例 |
|------|------|----|
| 太字 | `**テキスト**` | **重要** |
| イタリック | `*テキスト*` | *強調* |
| 太字イタリック | `***テキスト***` | ***非常に重要*** |

- 強調記号の内側にスペースを入れない
- 大文字・大文字化で代用しない
- 複数行にわたるセクションの強調には使わず、見出しを使う

## リンク

- **インラインリンク形式** を基本とする

```markdown
[リンクテキスト](https://example.com)
[リンクテキスト](https://example.com "タイトル属性")
```

- リンクテキストは「こちら」「リンク」「詳細」などの無意味な語を使わず、内容が伝わる言葉にする
- URLは `https://` を優先する
- URLが長い場合は参照スタイルを使って本文の可読性を保つ

```markdown
[リンクテキスト][ref-id]

[ref-id]: https://example.com
```

- 裸のURLをそのまま本文に貼り付けない。リンク形式か山括弧で囲む（`<https://example.com>`）

## 画像

```markdown
![代替テキスト](path/to/image.png)
```

- 代替テキスト（alt属性）は必ず書く。ファイル名をそのまま使わず、内容を説明する文にする

## テーブル

- GFM形式のテーブルを使う
- セパレーター行のハイフンは最低3つ（`---`）
- 前後に空行を1行入れる
- 列数はすべての行で揃える

```markdown
| カラムA | カラムB | カラムC |
|---------|---------|---------|
| データ  | データ  | データ  |
```

列の配置指定：

```markdown
| 左揃え | 中央揃え | 右揃え |
|:-------|:--------:|-------:|
```

- 本当にテーブルが必要なデータにだけ使う。少ない項目なら箇条書きで書く

## 改行・空行

- ブロック要素（段落・見出し・リスト・コードブロック・テーブル）の間には **空行を1行** 入れる
- 連続する空行（2行以上）は使わない
- 文中に強制改行（ハードラインブレイク）が必要なときは行末に `\` を置く（2スペースは使わない）

## 行末の空白

- 行末の余分なスペースは取り除く
- ハードラインブレイクに2スペースを使わない（`\` を使う）

## ファイル末尾

- ファイルの末尾は **改行1つ**で終わる
- ファイル末尾に空行を複数置かない

## その他

- インデントはスペースを使う。タブは使わない
- 水平線が必要な場合は `---` を使う（`===` や `***` は使わない）
- `---` の前後に空行を1行入れる

## 数式（LaTeX）

CommonMark 標準には数式記法がなく、プラットフォームごとに拡張が異なる。
このプロジェクトの投稿先（Qiita・Zenn・GitHub）はいずれも LaTeX 記法をサポートしている。

### インライン数式

`$...$` でテキスト中に数式を埋め込む。

```markdown
二次方程式の解は $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ で求められる。
```

**注意点：**

- `$` の直後・直前にスペースを入れない（`$ x $` は Zenn でレンダリングされない）
- 数式内にアンダースコア（`_`）・波括弧（`{}`）・角括弧（`[]`）・山括弧（`<>`）が含まれる場合、Markdownパーサーと競合することがある
  - Qiita では `_` がイタリック記法と競合しやすい。下付き文字が複数ある場合は2つ目以降をエスケープする（例: `\hat{\mathbf{y}\_i}`）
  - GitHub では競合が多い場合、バックティック付きのインライン記法（`` $`...`$ ``）を使う

### ブロック数式（ディスプレイ数式）

`$$` を単独行に置き、その間に数式を書く。

```markdown
$$
\left( \sum_{k=1}^{n} a_k b_k \right)^2 \leq
\left( \sum_{k=1}^{n} a_k^2 \right)
\left( \sum_{k=1}^{n} b_k^2 \right)
$$
```

**注意点：**

- `$$` は単独行に置く（行末に数式を続けて書かない）
- `$$` ブロックの前後に空行を1行入れる
- `$$` と数式の間に空行を入れない（Zenn ではレンダリングが壊れる）
- GitHub では `$$` の代わりにフェンスコードブロック（`` ```math ``）も使える

```markdown
```math
\left( \sum_{k=1}^{n} a_k b_k \right)^2
```
```

### 複数行の数式

複数行の式を縦に揃えるには `aligned` 環境を使う（`align` ではなく `aligned`）。

```markdown
$$
\begin{aligned}
f(x) &= x^2 + 2x + 1 \\
     &= (x + 1)^2
\end{aligned}
$$
```

### プラットフォーム別の対応まとめ

| プラットフォーム | インライン | ブロック | レンダラー |
|-----------------|------------|----------|------------|
| Zenn | `$...$`（`$` 前後スペース不可） | `$$\n...\n$$` | KaTeX |
| Qiita | `$...$`（`_` に注意） | `$$..$$` または `` ```math `` | MathJax |
| GitHub | `$...$` または `` $`...`$ `` | `$$..$$` または `` ```math `` | MathJax |

### よく使うLaTeX記法

```markdown
# 分数
\frac{分子}{分母}

# 平方根
\sqrt{x}  \sqrt[n]{x}

# 上付き・下付き
x^2  x_i  x_{i,j}

# ギリシャ文字
\alpha  \beta  \gamma  \mu  \sigma  \theta

# 総和・総乗
\sum_{i=1}^{n}  \prod_{i=1}^{n}

# 積分
\int_{a}^{b} f(x)\,dx

# 行列
\begin{pmatrix} a & b \\ c & d \end{pmatrix}

# テキストを数式内に混在させる
\text{テキスト}
```
